# Murder Card Game: Design Document

  * author: *Avo Estevez*
  * date: October, 8 2026

## phases

Roll Die <--------------------------------------- 
    -> Assign Die                               | 
        -> Rummage X Cards                      |  
            -> Choose Murder                    | 
                -> Return To Deck               | 
                    -> Shop Populate            |
                        -> Choose Buy           |
                            -> Choose Murder    |
                                -> Return To Deck

Remove Murdered Cards -> Place cards till slots are full
